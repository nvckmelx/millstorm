# Millstorm — Art Pack 01

Набор для текущего прототипа, сверенный с Claude Code Cloud: `prototype-week1`, `e9dc58f`.

**29 PNG-листов, 145 растровых кадров и 20 отдельных SVG-эффектов.** Открыть `index.html` в браузере для каталога, поиска и просмотра при 32/64 px на разных фонах. Все PNG-листы сопровождаются TexturePacker JSON Hash для Phaser. Исходные PNG сохранены без пересжатия и изменения пикселей.

## Состав

- 6 башен × 3 уровня + кормушка = 19 состояний. IDs: scarecrow, pumpkin, ballista, owl, sprinkler, bell, feeder.
- 7 мобов: mouse, beetle, ferret, crow, snail, spore, goat. На каждого 4 варианта позы: side_a, side_b, down_a, down_b.
- 3 босса: badger, locustQueen, stormcloud. По 4 варианта позы.
- Мельница: 4 состояния корпуса и 3 отдельных ротора; пушка 0–5.
- 16 тайлов, 9 объектов окружения, небо.
- 16 значков ресурсов/действий, 9 значков типов боя/статусов, 6 пингов, 3 награды, 4 гусиные эмоции.
- 9 растровых снарядов/частиц, 20 масштабируемых SVG-эффектов и маркеров.

## Подключение

1. Скопировать папки `towers`, `enemies`, `world`, `ui`, `fx` и `manifest.json` в `client/public/art/`. Копировать и PNG, и лежащие рядом JSON.
2. Использовать относительные URL `art/...`, без ведущего `/`, чтобы сохранить офлайн-сборку с `base: './'`.
3. В `preload` загрузить `manifest.json`, затем каждый лист через `this.load.atlas(sheet.key, 'art/'+sheet.file, 'art/'+sheet.atlas)`. Для манифеста нужен отдельный Boot scene или предварительный импорт JSON.
4. SVG грузить `this.load.svg(asset.id, 'art/'+asset.file, {width:256,height:256})`.
5. Имена кадров точные, например `defender/scarecrow/l1` и `enemy/locustQueen/down_a`. `mice` → `mouse`, `crows` → `crow` — IDs отправок, а не новые враги.

Пример после загрузки:

```js
const sprite = this.add.image(x, y, 'scarecrow-levels', 'defender/scarecrow/l1');
// Выбрать размер по видимым границам, а не по пустым полям холста.
const frameInfo = manifest.sheets.find(s => s.key === 'scarecrow-levels').frames[0];
const [left, top, right, bottom] = frameInfo.visibleBounds;
sprite.setOrigin(frameInfo.pivot.x, frameInfo.pivot.y);
sprite.setScale((0.78 * cell) / (right - left));
```

Для врагов `enemyRadiusCells` содержит текущие радиусы из рендера. Размер по ширине тела — приблизительно `2 * radius * cell`; у рогов/крыльев может понадобиться ручная корректировка. Для движения влево зеркалить боковой кадр. Не вращать персонажа целиком вслед за направлением пути. Опорные точки в JSON рассчитаны по видимым границам и являются начальной настройкой.

В UI можно использовать CSS `background-image/background-position/background-size` по `manifest.json`, как в каталоге. Карточки строительства и отправок переиспользуют соответствующие кадры башен/мобов; это не отдельные изображения.

## Состояния мельницы

`healthy`: HP > 30%; `damaged`: HP ≤ 30%; `critical`: HP ≤ 15%; `destroyed`: HP = 0. Ротор отдельный; при 0 HP убрать/остановить его. Пушка уровня 0 отсутствует; изображение пустого крепления — дополнительный декоративный вариант, не обязательный объект.

Крылья нарисованы фронтально для вращения в 2D. Их точку крепления и масштаб следует настроить к сокету корпуса. Цвет команды показывать отдельным флагом, кольцом или окрашиваемой накладкой; не перекрашивать весь рисунок.

## Проверка и ограничения

- Это готовый набор исходной графики, **не подтверждённая интеграция в игровой клиент**. Исходный репозиторий и баланс этим архивом не меняются.
- A/B — нарисованные варианты поз, не гарантированно плавные циклы. Начать со статичного направления; включать чередование только после проверки размеров и опорных точек. Мышь и некоторые другие варианты близки по позе.
- Не считать тайлы бесшовными без проверки. На границах листа есть тонкие разделители; при подключении можно исключить 1–2 пикселя рамки координатами кадра. Стыки и ширина тропы требуют проверки на настоящей карте.
- Атласы имеют исходные размеры 1254×1254 или 2172×724; некоторые ячейки различаются на 1 пиксель. Использовать приложенные JSON, а не предполагать кадры 128×128.
- Круг радиуса, полосу HP, цвет команды, подписи отправителя, рамку поля и адаптивные панели лучше оставлять в Phaser Graphics/CSS. Для них уже есть точные размеры и интерактивные состояния; декоративные SVG можно накладывать поверх.
- Замедление, лужа, облако спор при смерти, попадание/смерть и кража зерна частично отсутствуют в текущем снапшоте. Их нельзя достоверно показывать по одним позициям; сначала нужны события/состояния симуляции. Баланс не менять.
- `qa-report.json` проверяет размеры, наличие альфа-канала и число кадров. Это не заменяет визуальную проверку в Phaser.
- Основная растровая графика создана встроенным imagegen. После достижения лимита отдельные простые эффекты выполнены как редактируемые SVG, а не растр. Промпты, включая невыбранные попытки, сохранены в `generation-prompts.json`.
