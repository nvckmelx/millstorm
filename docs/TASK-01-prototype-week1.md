# Задача 01 — Прототип, неделя 1: ядро + первый PvP-цикл

Прочитай `CLAUDE.md`, затем разделы 3–7, 14 и 18 в `docs/design.md`. Данные — в `shared/data/`.

## Цель
В конце задачи два браузерных окна подключаются к одной комнате по коду и играют 1v1: строят Стражей, отбивают волны 1–10, отправляют друг другу вредителей, у каждого Мельница со 100 HP, есть победа/поражение. Графика — простые фигуры.

## Шаги (делай по порядку, коммит после каждого)
1. **Каркас репозитория.** npm workspaces `shared`, `server`, `client`; TypeScript strict; Vitest; скрипты `dev`, `build`, `test` в корне (dev запускает сервер и клиент вместе).
2. **shared: загрузка данных и типы.** Типы для `balance.json` и `waves.json`, функция загрузки с проверкой (например, zod).
3. **shared: симуляция одной линии.** Поле 10×16, тропа по waypoints, спавн волны по `spawnIntervalSec`, движение врагов по `progress`, Стражи `scarecrow`, `pumpkin`, `ballista`, `owl` (цели: первый по тропе в радиусе), урон с множителями из `damageMultipliers`, сплэш, летуны игнорируют наземные башни, смерть → награда Зерном, утечка → урон Мельнице.
4. **shared: цикл матча.** Старт 30 с → волны по 15 с подготовки + 35 с боя (следующая идёт по таймеру), доход в конце волны `incomeBase + incomePerWave × N + бонус отправок + cleanWaveBonus`, Приманка +1/с до 150, продажа 100% в ту же подготовку / 70% позже, апгрейды до ур. 3.
5. **shared: отправки.** `mice`, `beetle`, `crows` из `sends`; очередь до закрытия за 3 с до волны; юниты появляются у соперника вместе с его следующей волной; `incomeGain` навсегда добавляется к доходу отправителя; открытие с волны 4 (вороны — 7); убийство чужого вредителя даёт защитнику 30% его цены Зерном.
6. **Тесты Vitest:** урон с множителями, доход волны (пример из раздела 5: волна 5, 3 отправки мышей, без утечек = 71), валидация постройки на тропе, утечка снижает HP, победа при HP = 0.
7. **server: Colyseus `MatchRoom`.** Создание комнаты с 4-символьным кодом, вход по коду, 2 игрока, тик 20 Гц, команды `build {defender, col, row}`, `upgrade {id}`, `sell {id}`, `send {sendId}` с серверной валидацией, состояние: ресурсы, HP Мельниц, фаза и таймер, Стражи, враги (id, type, progress, hp), очереди отправок.
8. **client: Phaser.** Экран «Лобби» (создать комнату / ввести код, ник), экран «Матч» по вайрфрейму из раздела 17: своё поле крупно, мини-поле соперника, таймер, ресурсы, HP обеих Мельниц, 4 кнопки постройки (Q–R) и 3 кнопки отправки (1–3), полоска «Идут к тебе». Враги — кружки цвета типа брони, Стражи — квадраты со значком уровня. Интерполяция позиций между снапшотами.
9. **README:** как запустить локально и как сыграть вдвоём в двух вкладках.

## Критерии готовности
- `npm install && npm run dev` поднимает всё; две вкладки играют матч до победы одного игрока.
- `npm test` и `npm run build` проходят.
- Все числа читаются из JSON; поменял `balance.json` — поведение изменилось без правок кода.
- Нет чужих ассетов и названий.

## Вне этой задачи
Боты, 2v2/3v3, пинги, Налёт, Колокол/Разбрызгиватель/Кормушка, остальные вредители, деплой, арт — следующие задачи.
