# Архив: стиль «Гербовник» (v2)

Пиксельный герб Millstorm и генератор, который его рисовал. Заменён рисованным логотипом-мельницей
(`docs/brand/source/millstorm-logo.webp`) и стилем «Мельничная мастерская». Файлы хранятся для истории;
пути внутри `brand_exports_armorial.py` указывают на старое расположение, скрипт в этом виде не запускается.
