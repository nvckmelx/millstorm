# Millstorm

Браузерная PvP tower defense: защищай свою небесную ферму и насылай вредителей на ферму соперника. 1v1 / 2v2 / 3v3 с друзьями по ссылке. Полный дизайн — `docs/design.md`.

## Быстрый старт (локально)

Нужен Node.js 20+.

```bash
npm install
npm run dev
```

- Клиент: http://localhost:5173, сервер: порт 2567.
- **Сыграть вдвоём в двух вкладках:** в первой вкладке введи ник → «Играть с друзьями» → «Скопировать ссылку». Открой ссылку (`http://localhost:5173/p/КОД`) во второй вкладке, введи другой ник → «Войти в лобби». Лидер выбирает режим 1v1, оба жмут «Готов», лидер — «Старт». Пустые места в 2v2/3v3 займут боты.
- **Без сервера:** «Обучение» и «Против ботов» работают целиком в браузере.

## Играть с друзьями по интернету

Сервер и клиент собираются в один Node-процесс: он раздаёт игру и держит WebSocket на одном порту.

```bash
npm run build
PORT=2567 npm start        # открыть http://<адрес-сервера>:2567
```

- **В одной сети (LAN):** запусти на своём компьютере и дай друзьям `http://<твой-локальный-IP>:2567`.
- **Хостинг:** в репозитории есть `Dockerfile` и `render.yaml`. Подойдёт любой хостинг с Docker и WebSocket (Render, Fly.io, Railway, VPS). Для Render: New → Blueprint → выбрать репозиторий. Проверка здоровья — `/health`.
- Ссылки-приглашения имеют вид `https://<домен>/p/K7F2`.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | сервер (2567) + клиент (5173) с перезагрузкой |
| `npm test` | тесты Vitest для `shared/` |
| `npm run build` | проверка типов + сборка клиента и сервера |
| `npm start` | продакшен-сервер (`server/dist`) + собранный клиент |
| `npm run sim -- 1 20` | 20 матчей бот-против-бота 1v1 без графики — для баланса |
| `npm run build:offline -w client` | офлайн-сборка (только боты) в `client/dist-offline`, открывается с любого статического хостинга |

Для тестов: `SIM_SPEED=10 npm run dev` ускоряет матчи на сервере, `?speed=10` в адресе ускоряет офлайн-матч (только в dev).

## Управление

Q–U — Стражи (клик по траве — поставить, Shift — ещё, ПКМ/Esc — отмена) · клик по Стражу → Z улучшить, X продать · 1–7 — отправки · клик по сопернику справа — сменить цель · Alt+клик по полю — колесо пингов.

## Как устроен код

```
shared/   правила и симуляция (без DOM и Node API): data.ts (zod-проверка JSON), match.ts (матч),
          bot.ts (бот на правилах), snapshot.ts (компактное состояние для клиента), lobby.ts
shared/data/balance.json, waves.json — все числа баланса; меняются без правок кода
server/   Colyseus: одна комната GameRoom = одна пати (лобби → загрузка → матч → итоги → реванш)
client/   Vite + Phaser 3: поле игрока рисует Phaser, интерфейс — HTML/CSS
```

- Сервер авторитетный: симуляция 20 тиков/с, клиент шлёт только команды, сервер проверяет каждую (zod + правила матча) и рассылает снапшоты 10 раз/с. Клиент интерполирует позиции.
- Офлайн-режим запускает ту же симуляцию из `shared/` в браузере — только против ботов, поэтому читерство там не важно.

## Что сделано из MVP (раздел 2 дизайн-документа)

- Карта «Долина Мельниц»: поле 10×16, фиксированная тропа, Двор с Мельницей.
- 6 Стражей + Кормушка, 3 уровня, эффекты ур. 3; типы урона «что против чего» с цветами.
- 7 вредителей для отправки, 18 волн с 3 боссами, внезапная смерть с волны 19.
- Экономика: Зерно, Приманка, доход за волну, бонус чистой волны, 30% за чужих вредителей, «Второе дыхание», продажа 100%/70%.
- Команда: общая Мельница, пушка Мельницы, подарок Зерна, «Налёт», смена цели, пинги и стикеры-гуси, авто-сигналы («течёт», «идёт таран»).
- Пати по ссылке и коду, выбор режима, готовность, чат пати, поиск матча с заполнением ботами, реванш в 1 клик, счёт серии, переподключение 90 с (линию держит бот).
- Обучение: матч 1v1 на 8 волн против лёгкого бота с подсказками.
- Итоги: график HP, плашки-награды, совет, «Мельницу сломал козёл игрока X».

## Упрощения и что дальше

- Графика — простые фигуры, звука нет (по плану арт — следующий этап).
- Вороны летят по тропе, а не по прямой.
- Щит слизня выдаётся каждому вредителю один раз.
- Пинги союзников видны в интерфейсе только союзникам, но приходят всем клиентам.
- В публичном поиске вместо ready-check — автостарт по таймеру (20 с, затем боты).
- Баланс не выверен: матчи ботов идут 16–20 минут, «жадный» бот слабее остальных. Цифры — в `balance.json`, проверка — `npm run sim`.
- Нет английской локализации, мобильной версии и деплоя по умолчанию.
