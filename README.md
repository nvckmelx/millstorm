# Millstorm

Браузерная PvP tower defense: защищай свою небесную ферму и насылай вредителей на ферму соперника. 1v1 / 2v2 / 3v3 с друзьями по ссылке.

## Что здесь сейчас
- `docs/design.md` — полный MVP design doc.
- `docs/TASK-01-prototype-week1.md` — первая задача для разработки.
- `shared/data/balance.json`, `shared/data/waves.json` — стартовый баланс и 18 волн.
- `CLAUDE.md` — правила проекта для Claude Code.

## Как начать в облачной сессии Claude Code
1. Загрузи содержимое этой папки в новый GitHub-репозиторий `millstorm` (ветка `main`).
2. Открой claude.ai/code, подключи GitHub, выбери репозиторий.
3. Первое сообщение: «Выполни docs/TASK-01-prototype-week1.md».
